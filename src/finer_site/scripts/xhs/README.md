# 小红书素材 · 封面生成

```bash
cd src/finer_site/scripts/xhs
NODE_PATH=../../../finer_dashboard/node_modules node render-covers.cjs ./out
```

输出 1242×1656（3:4）PNG 到 `./out/`。改文案只需编辑 `covers.html` 里对应
`.cv` 块的文字，样式与版式不用动。

## 为什么导出前会被拒

`render-covers.cjs` 把三条红线做成了**断言**，不通过直接 exit 1、不出图：

1. `.num` 含 `%` 时，`.unit` 必须写样本量，且字号 ≥ `.num` 的 22%
   （比率不得裸奔——见 CLAUDE.md「定位前提」第 1 条）
2. 数据型封面必须有非空 `.disclaim`
3. 主标 / 主数必须完整落在黄金带 `y ∈ [414,1242]`
   （小红书会把封面重裁成 4:3，带外的会被切掉）
4. 禁用词表扫描：跟单 / 荐股 / 稳赚 / 必涨 / 抄底 / 买入 / 卖出 / 推荐 /
   最准 / 排名 / 预测未来

第 4 条**不认否定式**：写「不是排名」照样拦——小红书的图像通道是 OCR + 词表，
机器初审不做语义判断，看到词就是看到词。首次渲染就是被这条拦下的。

## 版式约束（改文案时会踩到）

| 层 | 字号 | 单行中文上限 |
|---|---|---|
| L1 主标（`.head`） | 140px 宋体 | **7 字 / ≤3 行** |
| L2 副标（`.sub` / `.unit`） | 52 / 64px | 19 字，超了自己加 `<br>` |
| D1 巨数（`.num`） | 280px 等宽 | 6 字符 |
| `.mini .v` | 56px | 5 字符，超了会压到下一栏 |

字体走系统栈（站点未用 `next/font`），macOS 本机渲染即与线上一致。
