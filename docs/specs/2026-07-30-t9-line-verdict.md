# T9 板块信号线 — 结论与建议（2026-07-30）

> 基于 3,292 份 T9 池研报（金丝雀 999 + 2025 段 2,293）走完 F0→F5→F8 的实测。
> 前序：`2026-07-29-c10-canary-report.md`（机械数据）、`2026-07-29-c10-canary-findings.md`（缺陷与漏斗）。

## 结论

**不建议为产出 TradeAction 而跑满 T9 池。** 三项独立事实指向同一结论：

| 事实 | 数值 | 性质 |
|---|---|---|
| 适配率 | **2.7%** | 三次测量（n=1,148 / 2,872 / 3,441）全部 ±1pp 内，结构性常数 |
| 转化率 | **46%** | 瓶颈是证据粒度错配（§3.7），非配置或代码问题 |
| 业绩 | **与全语料持平** | 见下 |

## 1. 业绩：无超额

| | n | 胜率 | 均值 | 中位 |
|---|---|---|---|---|
| **t9i 板块信号** | **57** | **45.6%** | **+1.13%** | **−10.34%** |
| 全语料基准 | 2,240 | 42.9% | +1.30% | −5.79% |

胜率高 2.7pp、均值低 0.17pp、**中位低 4.55pp**。综合判断：**无实质超额**。

退出结构：`stop_loss` 31 / `time_exit` 13 / `target_reached` 13 —— 止损占 54%，与全语料的高止损特征一致。

### ⚠️ 一次必须记录的结论反转

样本 n=30 时（2026-07-29 20:00 左右）曾测得胜率 63.3%、均值 +6.98%、中位 +10.46%，
看起来**显著优于基准**。样本扩到 n=57 后全部回归至持平。

芯片 ETF（159995.SZ）反转最剧烈：n=18 时胜率 66.7%，n=35 时 40.0% —— 新增的 17 条几乎全亏。

**教训**：这条线的样本高度集中在同一时间窗与少数标的，n<50 的任何结论都不可信。
当时已标注"样本太小、不能当定论"，但呈现方式仍容易让人形成正面印象——
小样本结果应当**默认不展示主表**，或只报区间。

### 剔除芯片后的残余信号（不构成结论）

剔除 159995.SZ 后 n=22：胜率 54.5%、中位 +7.18%，仍优于基准。
但这与当初"n=12 看起来很好"的处境同构，**不据此下结论**。

## 2. 转化链路的真实折损

```
3,292 份 T9 池研报（已过 F0→F1→F2）
  → 92 条 adapted intent                    (2.7%)
      → 59 条本轮桥接（31 条前轮已出 action）
          → 27 条 → action                  (46%)
          → 19 条 → evidence_not_grounded_in_f2
          → 13 条 → evidence_empty_not_auditable ← 本轮新增的护栏拦下
```

**t9i action 累计 58 条，全部 `canonical_trace_status=canonical`。**
三向审计 **3,371/3,371 = 100%**（span 级 114,728/114,728）。

`evidence_empty_not_auditable` 在更大样本上拦下 13 条 —— 若无该护栏，
这些会带空证据落盘并再次破坏 C8 的 100%，证明了护栏的必要性。

## 3. 为什么转化率低是结构性的

见 `2026-07-29-c10-canary-findings.md` §3.7：**证据门是实体中心的，板块判断是主题中心的。**

`_resolve_f2_grounding` 把 `block_ids` 映射到 F2 evidence span，而 F2 只在识别出**实体**处生成 span。
宏观/板块研报的典型段落可以通篇不点名任何可交易标的 → 无 span → 证据锚落空。

**这个流失是正确的**：拿不出实体级证据就不该产出可审计的交易动作。

## 4. 建议

### 不做
- ❌ ~~跑满 2025 段剩余 11,583 份~~ → **此条已被 `2026-07-30-credibility-persistence-test.md` §6 反转**。
  本文的否定依据是「产出 action 数量」口径；而跨期持续性检验发现，那 11,583 份是**前期样本**，
  是唯一能让「信源可信度可预测」这一产品前提变得可检验的路径。按后者口径应当跑完。
  本文其余结论（T9 池产 TradeAction 的性价比不成立）不受影响。
- ❌ 跑 2026 段（3,748 份，且需先决策 OCR 成本）
- ❌ 为提高产出而放宽证据门

### 若仍要投入 T9，先做这个
**为板块判断设计独立的证据契约**，不复用实体 span。在此之前跑量，只是在同一个证据门上重复流失 54%，且产出与基准无异。

### T9 的真正价值可能在别处
51% 的 T9 行是 `cycle_view=mixed` 的宏观研报——它们对"这个板块当前处于什么周期"这类**叙事性上下文**有价值，而 F7 时间线正需要这类原料。
把它们塞进以实体证据为准绳的 TradeAction 管道是**用错了地方**。

## 5. 本轮的沉淀（与 T9 决策无关但长期有效）

即使 T9 线本身不再推进，本轮产出的这些是净收益：

- **`_find_content_record` 131 倍提速** —— 每条目 rglob 整棵 F0_intake 树，随语料增长劣化（实测 12.9→2.0 份/分钟）。影响所有走 driver 的批处理。
- **vision token 记账补齐** —— 此前最大消耗方完全不在账上，成本外推是空的。
- **`evidence_empty_not_auditable` 护栏** —— 堵住 `envelope_has_f2` 逃生门在真实无 span 信封上失效的漏洞。
- **sector intent 绕过实体锚点桥** —— 否则任何板块类适配器产出都会全军覆没。
- **T9 引句→F1 块的证据匹配**（文档级 83%）+ CJK 计权阈值。
