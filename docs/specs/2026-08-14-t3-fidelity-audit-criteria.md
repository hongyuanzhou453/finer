# T3 抽取保真度抽检 — 判据（先于抽样与结果写死）

写于开跑之前。任何在看到结果后放宽判据的行为都使本次检验作废。

## 目的

回答一个问题：**「记录是准的」这句话，误差率上界是多少。**

新定位（「不告诉你谁更准，让你查得清谁说过什么」）的全部资本是记录本身的
保真度。此前唯一落盘的证据是 `data/_audit/no_occurrence_diagnosis.json` 的
`n=40 / t3_hallucination=1`——Wilson 95% 上界约 10.7%，且抽样框取自
`no_occurrence` 桶（有选择偏倚）。本次改为**全语料随机**。

## 抽样框与样本量

- 抽样框：`data/F3_intents/bri_*.json` 全部 5,852 条现役 intent，**无任何筛选**。
- 样本量 n = 150，`random.Random(20260814).sample()`，种子写死。
- 抽中但 T3 侧无对应 report_id 的，记为 `join_miss`，**不替换补抽**
  （替换会把「连接不上」这个真实缺陷从分母里洗掉）。

## 逐字段判据

对每条记录核对 4 个字段。真值 = **原始 PDF 的文字层**（`pdftotext`）。

| 字段 | 判 `match` 的条件 | 判 `mismatch` 的条件 |
|---|---|---|
| `ticker` | PDF 中出现该标的的任一常见写法（本地代码 `9868.HK`/`9868`、美股 ADR 码、公司名中文或英文），且指向同一家公司 | PDF 通篇指向**另一家**公司 |
| `rating_current` | PDF 中出现该评级词或其公认同义写法（Buy/买入/增持、Overweight/超配、Hold/中性/持有、Sell/卖出/减持…），且是**本报告给出的**评级 | PDF 明确写的是**方向相反或不同档**的评级 |
| `target_price` | 数值与币种同时在 PDF 中出现且属于该标的的目标价 | 数值在 PDF 中不存在，或明显属于别的标的/别的口径（如上年收盘价） |
| `report_date` | 与 PDF 内标注的报告日期一致（±1 天容差，跨时区发布） | 相差 >1 天 |

**`unverifiable`（不计入错误率的分母之外，单独报）**：
- PDF 无文字层（图片型，`pdftotext` 输出 < 200 字符）
- PDF 文件在 `filepath` 处不存在
- 该字段在 intent 里本就是 null（例如没有目标价）——记 `not_applicable`

**存疑一律判 `match`。** 本次要估的是「错误率上界」，宁可低估错误也不要用
模糊判断制造假错误；真有问题的会在 mismatch 里以确凿证据出现。

## 预声明的结论口径

- 主指标：**逐字段错误率** = mismatch / (match + mismatch)，各字段分别报，
  并给 Wilson 95% 区间。
- 次指标：**整条记录全对率** = 4 个字段全 match 的记录数 / 可核验记录数。
- 覆盖率如实报：`join_miss`、`no_text_layer`、`file_missing` 各自的条数。

## 不做的事

- 不因为结果难看就换抽样框、改容差、剔除「特殊情况」。
- 不把 `unverifiable` 计入 match（那会把「查不了」洗成「查对了」）。
- 不由抽检本身修改任何数据；发现的问题只记录，修不修另行决定。
