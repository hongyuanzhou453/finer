# 国际股日历错配 — 只读影响评估（2026-07-25）

> 性质：**只读评估，未改任何数据**。用于决定「回写 market + 重结算」这个批次做不做、按什么优先级做。
> 评估脚本：`scratchpad/assess_intl_calendar_impact.py`（一次性，不进仓）。
> 前置：本轮 B1 已修前向推断（`infer_market` 委托 `normalize_broker_ticker` + 30 市场会话表）；存量未回写。

## 1. 方法（为什么不用取行情也能定论）

`entry_date_of(action)` = `execution_timing.action_executable_at`（缺则 `intent_effective_at`）的日期。
而 `evaluate_action` 把**实际选中的入场 bar** 写进了 `backtest_period` 的首段（`{entry_day} — {exit_day}`）。

由于 `entry_idx` = 第一根 `d >= entry_date` 的 bar，而 `B_old` 按定义就是第一根 `>= old_entry` 的 bar，
可在**零行情请求**下严格分类：

| 新入场时钟 | 判定 | 理由 |
|---|---|---|
| `new_entry ∈ [old_entry, B_old]` | **同一根 bar，无变化** | 区间 `[old_entry, B_old)` 内按定义不存在 bar |
| `new_entry > B_old` | **必然换 bar（更晚）** | 原 bar 不再满足 `d >= new_entry` |
| `new_entry < old_entry` | 可能变化 | `[new, old)` 内可能有更早的 bar |

## 2. 规模

**870 条** action 的 `execution_timing.market` 与其 ticker 归一化出的真实市场不一致（不止先前估的 ~830；
该数按市场码严格比对，且包含 `.SH` bug 波及的 CN 13 条与 HK 12 条）。其中 settled 514 / unsettled 356。

主要重映射：JP 176、UK 108、FR 90、TW 85、IN 84、AU 70、KR 52、NL 26、CN 23、DE 23、DK 16、NO 13…

## 3. 判定结果

| 判定 | 条数 |
|---|---|
| settled — 同一根 bar，**无变化** | 277 |
| settled — **必然换 bar（更晚）** | **237** |
| unsettled — 入场日不变 | 226 |
| unsettled — 入场日 +1 天 | 130 |
| 可能提前（`new < old`） | **0** |

入场日位移分布：`+0d` 500、`+1d` 361、`+3d` 9（跨周末）。

**位移方向 100% 单向：没有任何一条会提前入场。** 即：US 日历对国际股是**一致偏宽**的。

物理含义清晰——高盛在纽约时间某日上午发的日本股研报，东京当天早已收盘，实际最早只能次日成交；
而 US 日历允许了「当日入场」。这 237 条是**真实存在的 look-ahead（前视偏差）**，不是口径争议。

## 4. 关键结论：look-ahead 并未实质抬高该组的测量结果

用同一总体内的准对照组比较（均为改前的已记录结果）：

| 组 | n | 胜率 | 均值 | 中位数 |
|---|---|---|---|---|
| 全语料 | 2,241 | 44.1% | +1.64% | −4.10% |
| 错日历国际股（全部） | 514 | 55.4% | +6.35% | +2.59% |
| └ 对照组（入场 bar 不受影响） | 277 | 54.9% | +3.98% | **+2.59%** |
| └ **look-ahead 组（入场偏早）** | 237 | **56.1%** | +9.11% | **+2.41%** |

- **胜率几乎相同**（56.1% vs 54.9%，差 1.2pp，n≈250 下属噪声）→ 前视没有系统性抬高胜率。
- **中位数几乎相同**（+2.41% vs +2.59%）→ 分布主体没有位移。
- 均值差（+9.11% vs +3.98%）**由少数厚尾样本驱动**，不是系统性抬升。

⚠️ 对照组的局限：分组不是随机的——是否落入 look-ahead 取决于发布时刻是否晚于当地收盘，
这与研报发布时段相关，可能间接与研报类型相关。因此这是**准对照**，不是严格对照。

**因此：修复的正当性是「审计正确性」（消除物理上不可能的成交），不是「修正被夸大的业绩」。**
预计重结算后总胜率变动 ≲1pp。

顺带一个独立观察（本次未深究）：错日历国际股整体胜率 55.4% 显著高于全语料 44.1%。这可能是
市场/期间/覆盖偏差，也可能是真实差异，值得单列课题——但**不能**用本次数据下结论。
