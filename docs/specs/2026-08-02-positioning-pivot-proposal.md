# 定位转向提案：从「预测谁更准」到「审计谁说过什么」

> 触发条件：`2026-07-30-next-actions-plan.md` P2 预先写明——若持续性检验不支持
> 产品前提，则产品定位讨论正式立项。该条件已于 2026-08-02 触发。
> 本文对着 `2026-07-18-product-north-star-architecture-roadmap.md` §6 的模块注册表
> 逐条判定：留、改、砍。

## 1. 触发依据（一句话）

在现有全部语料上（2,983 条已结算 action，2,889 条可用），**券商的历史超额表现
不能预测其未来超额表现**——两个指标、六个切分点、预先声明的判据，双双不成立。

| 指标 | 符号 | 中位统计量 | 判据（预声明） | 结果 |
|---|---|---|---|---|
| 超额**胜率** | 2 正 / 4 负 | 中位 \|z\| = 0.32 | 同号 且 >1.5 | ✗ ✗ |
| 超额**均值收益** | 1 正 / 5 负 | 中位 \|t\| = 1.20 | 同号 且 >1.5 | ✗ ✗ |

均值收益口径的符号偏负，即前期强的后期略弱（轻微均值回归），但未达显著。

### 1.1 这个否定结论的**边界**（不可越界引用）

- 适用于**券商层级**、**月度切分**、**每段 n≥30** 的口径。
- **不**适用于：分析师个人层级、行业层级、其他持有期规则、KOL（样本仅
  trader_ji n=60，不足以检验）。
- **不是**「券商研报没用」——是「按历史记分卡挑券商没有依据」。
- 语料为静态档案（覆盖约 10 个月有效窗），前期样本上限已到，
  因此这**不是**「样本不足待观察」。

## 2. 判定原则

一个模块的价值若依赖「历史表现可预测未来」，就必须改写或砍掉；
若价值来自「如实记录 + 可下钻核验」，则不受影响，甚至更重要——
因为当预测性不成立时，**记录的可信度就是全部产品价值**。

## 3. 模块逐条判定

### 3.1 不受影响（基建组，全部保留）

`OPS-1..6`、`AUD-1..4`、`MKT-1..3`、`PROJ-1..2`

这些是「让数字存在且可核验」的能力，与预测性无关。其中 **AUD 组的地位反而上升**：
三向审计 100%（4,577 条 / 124,988 span）从「护城河之一」变成**唯一的护城河**。

### 3.2 必须改写

| 模块 | 原设定 | 改写为 | 理由 |
|---|---|---|---|
| **CRD-1** credibility_engine | 「可信度**评分**」，隐含可据此选人 | **历史记录卡**（historical record card）：如实呈现命中率/收益/覆盖率，**移除任何排名即推荐的语义**，卡面强制附「本平台未观测到该指标的跨期持续性」 | 分数本身是真实的历史事实；错的是把它当预测器 |
| **UI-1** `/discover` 排行榜 | 按超额胜率排名的卡片墙 | 默认排序改为**样本量/覆盖率/最近活跃**，超额列保留但标注不可外推；禁止「Top 券商」式文案 | 一个按历史超额排序的榜单，本身就是在宣称预测性 |
| **PRT-2** equity_curve | 每 Creator 净值曲线（隐含「跟谁能赚」） | 保留为**历史事实的可视化**，与记录卡同样的口径声明；`data_start_date` 诚实暴露窗口长度 | 曲线是记录，不是承诺 |

### 3.3 地位上升

| 模块 | 新地位 | 理由 |
|---|---|---|
| **CRD-2** statistical_validity_gate | 从「配套硬门」升为 **P0 第一优先** | 本轮的教训正是「30pp 的横截面差距其实是噪声」。这个门是唯一能防止把噪声当能力呈现给用户的机制。没有它，记录卡就是在骗人 |
| **CRD-4** divergence_detector（言行不一） | 从 P1-P2 升为**旗舰功能** | 它是纯审计：说多做空是一个**可被证据锚定的事实**，不需要任何预测性假设即成立。这正是新定位的形态 |
| **CRD-3** consensus_aggregator | 保留原优先级，语义收紧 | 共识分布与目标价区间是**记录**（谁说了什么），不是**预测**（谁说得对）。已落盘 target_price 的第一个真实消费者，价值不变 |

### 3.4 建议砍掉或重构

| 模块 | 判定 | 理由 |
|---|---|---|
| **EXT-2** 合成策略层 | **「按信源打分选人」的版本作废** | 这是整份路线图里**唯一**其价值完全依赖本次被否前提的模块：策略规则 `creator_filter` 就是「挑历史分高的信源」。数据说这没有依据，做出来就是把噪声包装成付费产品 |
| | → **改为基于共识重构**（用户 2026-08-02 决定） | 见 §3.5 |

### 3.5 EXT-2 重构定义（用户已拍板：重构，不砍）

策略规则的输入从**信源身份**换成**共识结构**：

| 作废的规则元 | 替换为 |
|---|---|
| `creator_filter`（挑历史分高的信源） | `min_consensus_count`（至少 N 家独立信源同向） |
| 按信源评分加权 | 等权；或按**目标价上行空间**分档（CRD-3 已落盘 target_price 的真实消费） |
| —— | `dispersion_max`（目标价分歧过大时不入场，分歧本身是信号） |

**强制前置门（不可跳过）**：共识有效性是**另一个独立的、尚未检验的假设**，
不得因「听起来合理」而默认成立。EXT-2 上线前必须先过一次与本轮同规格的检验：

1. 判据**先于结果**写死在检验脚本里（仿
   `scripts/test_credibility_persistence.py` 的 `CRITERION_*` 常量）；
2. 遍历**全部**可行切分/参数点，不接受单一切口的正面信号；
3. 至少两个指标口径（胜率 + 均值收益）同时成立才算通过；
4. 未通过 → EXT-2 不上线，不得降低判据重试。

理由：本轮四次「中期正面信号被更多数据推翻」的教训，其成本已经付过一次；
共识假设若不设同样的门，会原样重演。

**排序**：EXT-2 仍归 P3，且其前置门依赖 CRD-3 产出真实共识数据，
因此不早于 CRD-3 落地。

## 4. 新定位的一句话表述

> **Finer 不告诉你谁更准。它让你查得清每一句话是谁在什么时候说的、
> 后来发生了什么、以及说的和做的是否一致。**

三条支柱，全部不依赖预测性：

1. **可下钻的记录**——每个数字 3 次点击内到达 EvidenceSpan 原文（AUD 组已就位）
2. **诚实的统计**——样本不足就说不足，无持续性就说无持续性（CRD-2）
3. **言行一致性核查**——说多做空、高调推荐后无声退出（CRD-4）

## 5. 对当前工单的直接影响

- **P4/CRD-1 不再是「若前提获支持才值得建」**——它值得建，但要按 §3.2 改写口径。
- **T6 EstimateRevision** 原绑定 CRD-1，判定不变（记录类数据，属支柱 1）。
- **OCR 决策（图片型研报 F1 文本层）** 判定不变：它服务于记录完整性，
  与预测性无关；但收益口径要从「多产 action」改为「多覆盖可审计记录」。
- 本次否定结论**不影响** T9 的既有判定（行业研报产 TradeAction 性价比不成立，
  依据独立）。
