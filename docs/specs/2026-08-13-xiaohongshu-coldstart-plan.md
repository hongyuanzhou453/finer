# Finer 小红书冷启动执行方案（v1，D1 = 2026-08-17）

## 0. 结论先行

**值得做，但它不是获客渠道，是可信度渠道。** 别指望小红书带来产品用户量——一个免费的网页查询工具，在一个不能放外链的平台上，转化路径天然是断的。它真正的价值是把"Finer = 那个连自己核心功能都敢删的研报档案"做成一个可被搜索的词。这个资产不依附平台，平台封号也带不走。按这个预期投入，30 天的成本是一个人每周约 6 小时（15 小时前置备料 + 每周 4 小时运营），值得付。

**最大风险不是限流，是标签跑偏。** 限流可查、可恢复、可换号重来。标签跑偏不可逆：一旦评论区被"XX 能买吗"占满、算法把账号打成荐股类，之后所有内容都进那个池子，来的全是求带的人，而这些人恰恰是产品要拒绝服务的对象。到那一步账号价值归零且救不回来。所以本方案里所有克制的规定——不回答个股操作、不做榜单、不用 emoji、不发在途标的——不是合规姿态，是标签防御。

**次风险（合规视角提出、我认同并已升为硬规则）：图像通道。** 小红书对所有图片做 OCR 并与正文同权重过词表。产品落地页上的累计收益曲线截图、`/kol-check` 的"真实战绩体检"标题，直接命中晒收益和荐股特征——文案改得再干净，配图一张就判掉。素材层已在 §4、§6 逐屏点名。

**第一步（本周内，D1 之前必须完成）：**
1. 注册个人号，昵称 `研报考古 · Finer`，小红书号改 `finer_os`，按 §2 填完简介。**先不认证专业号**。
2. 按 §4 做出 3 套封面模板 HTML，渲染出前 3 篇的全部图（约 20 张），存草稿箱。
3. 在站点加 `/xhs` 落地页（归因用，代码方案见 §5.4）——**这一步涉及生产部署，需要你确认后我再动手**。
4. 把 §6 的自查表打印/贴进备忘录。

## 2. 账号定位与设置（完整文案，可直接复制）

### 2.1 人设

**一个人做 Finer 的独立开发者。不露脸，不发日常，不出现"我们团队"，全程第一人称"我"。**

技术身份，不是金融身份。简介、评论、私信里一律不出现"投研""分析师""量化""操盘"这类词——它们会把审核尺度从"普通用户发言"切到"机构发布金融信息"。即使本人有证券从业资格也不要写。

第一人称只在两个场景出现：**技术选择的取舍**、**被数据打脸的时刻**。其余全是屏幕、表格、PDF 原文。

### 2.2 昵称与 ID

| 项 | 值 | 说明 |
|---|---|---|
| 昵称 | `研报考古 · Finer` | 主推。含搜索词根「研报」+ 品牌词。一年可改 2 次，粉丝过 3000 后可改纯品牌名 |
| 备选 A | `翻旧研报的人` | 若嫌「考古」太文艺 |
| 备选 B | `研报存档室` | 更冷、更工具向，涨粉更慢 |
| 小红书号 | `finer_os` | 一年可改 1 次。私信里说"小红书搜 finer_os"不算站外导流 |

**不叫「Finer」或「Finer OS」**：0 粉阶段品牌词搜索量为零，把最值钱的昵称位浪费在没人搜的词上。

### 2.3 简介（6 行，前 3 行是折叠前可见区）

```
一个人在做 Finer：把 28,565 份券商研报变成可逐条下钻的记录。
不判断涨跌，也不排「谁更准」——我检验过，历史胜率推不出后面的表现。
只做一件事：谁在什么时候说过什么，后来发生了什么，3 次点击回到原文。

这里发：研报考古 / 数据打脸现场 / 一个人怎么搓完这套系统
这是一个信息检索工具，不提供投资建议，不代客理财，不荐股
想自己查 → 私信「记录」
```

第 5 行是给人工复审和申诉看的意图证据（对机器初审无用，但在被举报时是明确的定性材料）。

### 2.4 头像

- 规格 800×800，深墨底 `#181512`，居中一个米白 `#f3efe7` 的「查」字（思源宋体 Heavy / Songti SC Bold），右上角 `#e11b22` 实心圆点，直径 = 画布 8%。

**正文**
```
券商研报的历史准确率，能不能用来判断以后该信谁？

我扒了 28,565 份，跑完之后的结论是：不能。

01 我原本想做什么

既然我能算出每家机构历史上说对了多少，那我就能告诉用户「听谁的更靠谱」。
这是这个产品商业上最值钱的一个功能，我做了半年。

02 我怎么检验的

跑数据之前，我先把判断标准写死了：用哪两个指标、在哪几个时间点切开、
达到什么程度才算站得住。先写下来，再看数据。
这一步是整件事里最关键的。不先写，人一定会替自己找补。

03 结果

两个指标 × 六个切分点，一个都没成立。符号是随机的。

翻译成人话：一家机构过去一段时间表现好，跟它接下来一段时间表现好，
在我这份数据里看不出关系。

那天晚上我盯着屏幕坐了很久，因为这意味着我最想做的那个功能不能做。
第二天我把它删了，定位改成：

不告诉你谁更准。让你查得清谁说过什么。

然后给自己定了三条不许绕的规矩：
一，样本不够时只报条数，不显示任何百分比
二，个股评级、板块观点、个人发言三种口径分开记账，绝不混算
三，列表默认按「已结算样本量」排，不按收益排，也不做榜单

这个方法的局限我也说清楚：它只覆盖了已经结算的样本，还没到期的那部分
没算进去，所以结论只对已结算部分成立。

现在这东西没那么性感了。它不再承诺你什么，只负责一件事：
你想知道某个信源当时说了什么、后来发生了什么，三次点击查到原文。

有人问这不是把护城河拆了吗。我的想法是，这个领域里敢说
「这个我不知道」的东西已经不多了。不知道本身也是一种信息。

你见过哪个产品主动把自己最赚钱的功能拆掉吗？

以上均为公开券商研报的原文记录与时间戳整理，不含方向性判断，
```

```
有一只在伦敦上市的药企股，我要把多家机构给的目标价聚合成一个区间。

01 案发现场

我去翻原始数据——
有的机构写的是英镑，比如 120
有的机构写的是便士，比如 12000
1 英镑 = 100 便士。

02 如果硬算会怎样

这两个数直接扔进一个中位数里，算出来的「共识价」会离谱到你笑出声。
可怕的地方在于：它长得非常像一个正经数字，你根本看不出它坏了。

03 系统的选择

不算。把这一栏留白，写清楚为什么不算，然后每一家的原始记录照样保留，
你想单独看哪家都能点开。

我越来越觉得，一个模型最贵的能力不是「什么都能答」，
是知道自己在哪一刻不该答。
会瞎编的那个省了你 3 秒，会说「我不知道」的那个可能省了你一笔钱。

顺手给个能直接用的判断法。以后看到任何一个「综合 / 共识 / 平均」的数字，
先问三件事：
它把什么口径混在一起算了
单位、货币、时间窗口统一吗
数据不够的时候，它是留白还是硬凑一个

能留白的，通常比什么都敢答的可信。

这个做法的局限是：留白会让页面看起来不完整，有人会觉得是功能没做完。
```

## 6. 合规自查清单 + 禁用词表

### 6.1 平台在查什么（三通道 × 三层 × 三档）

**三通道**：① 文字（标题/正文/标签/图片配文/评论/昵称/简介）② **图像（所有图片走 OCR，与正文同权重）** ③ 语音（视频走 ASR）。

**三层**：机器初审（秒级，纯词面+图像特征，**不看免责声明**）→ 人工复审（抽样/被举报/起量后，看语境）→ 举报驱动。

**三档处置**：限流不收录（静默，无通知）→ 违规下架 + 违规分 → 功能限制 / 封号。

**核心认知**：免责声明对机器初审零作用，只在人工复审加分。所以逐词规避一条都不能省。

### 6.8 风险预案（现在就做，出事后再做成功率大降）

1. **内容留档**：所有笔记本地保留原文 txt + 原图 + 发布时间 + 截图。用于申诉、迁号、平台删帖后的底稿。
2. **申诉素材包**：产品定位声明 + **系统层拒绝输出的证据截图**（样本不足只报计数、单位混存拒绝聚合）+ 来源合法性说明 + 无收费无社群无带单说明。申诉时的表述要点是**「我的产品在设计上就不可能提供投资建议，附机制证据」**，不是「我没违规」。机制证据的说服力是免责声明的十倍。
3. **不单点押注**：同一批内容同步知乎、即刻、公众号——这类理性投研内容在那边容忍度更高、受众更匹配，可能才是主战场，小红书是引流场。
4. **不开小号矩阵**：批量同质内容 + 同 IP 是营销号的强特征，会关联封禁把主号搭进去。

### 7.4 四种失败模式与对应止损

**模式 1 · 合规踩线导致限流（概率最高）**
- 表现：曝光断崖到 200 以下，或「仅自己可见」/「审核中」超 6 小时
- 判据：**连续 2 篇曝光 <300**
- 动作：立刻停发 3 天 → 删除最近 3 篇里含中危词或含 K 线/曲线类图的笔记 → 检查简介与评论区是否出现导流词 → 3 天后发一篇纯知识、零标的、零入口的内容试水，恢复到 500 以上说明是内容问题不是账号问题
- **不可逆判据**：停发 7 天后仍 <300 → 账号已被打标，不抢救，换号重开，把这个号当学费

**模式 2 · 受众分裂（最难察觉）**
- 表现：数据不难看也不好看，每篇 800–2000 曝光，永远出不了二级池
- 判据与动作见 D21 节点
- **常见误诊**：急着换选题，而实际卡点在封面点击率。先换封面

**模式 3 · 导流断裂（后果最严重）**
- 表现：曝光和粉丝都在涨，`/xhs` UV 几乎不动。根因是产品是网页工具，小红书内没有可完成的价值闭环
- 判据：**D30 时 `/xhs` 独立 UV <50 且私信触发 <10 次**
- 动作：**改产品形态而非导流话术**——执行 P10 那种「评论区留标的，我出图」的模式，把查询结果本身做成图片在小红书内消费完，站点降级为深度版。这条路能救，但要求你每天花 1 小时手工出图。**如果你不愿意付这个时间，那就是渠道不成立的信号，见下**

**模式 4 · 节奏不可持续**
- 判据：**连续 2 次未按日程表发布**
- 动作：立即降到每周 2 篇并公开说明（「最近在改 F2 的锚定逻辑，更新会慢」）。稳定的低频远好于断更

### 7.5 判定「这条渠道不成立」的终局条件

**同时满足以下三条，则关停小红书，把精力转到知乎/公众号：**

1. D30 时 12 篇里 **0 篇 >3000 曝光**，且 D14 已换过一轮封面与标题结构
2. `/xhs` 独立 UV **<50**，且你不愿意付「每天 1 小时手工出图」的代价（模式 3 的唯一解法）
3. 评论区里「求带 / 什么票能买」类提问占比 **>40%**——说明算法已把账号推给荐股受众，标签跑偏且不可逆

**只满足 1 条不是止损信号**，是调整信号。三条同时成立才说明这个平台的用户构成与产品服务的人群不重合——那不是执行问题，是渠道选错了，继续投入只会加深沉没成本。

**最后一条纪律**：止损判据最大的风险是被自我安慰绕过（「再发两篇看看」）。把 D14 / D21 / D30 写进日历并强制执行。同样地，前期数据平淡时**不要松红线**——「最准的分析师」这种标题能拿十倍点击，但它同时违反三条产品红线，且一旦营销素材上自我打脸，「不告诉你谁更准」这个定位就没了。那比低点击率贵得多。
