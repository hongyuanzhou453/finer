# 记分卡 v6 — 入场时钟口径重校准（2026-07-28）

> **口径断裂公告：v6 与 v1–v5 不可直接比较。** v1–v5 的入场时钟含系统性前视偏差
> （50.4% 的 action 在其研报日期之前入场）。v6 是第一个入场时钟正确的版本。
> 任何跨版本的数字对比必须先读本文。

## 1. 口径变更

| | v1–v5 | **v6** |
|---|---|---|
| 入场时钟 | date-only 的 `published_at`（当地零点）被当作真实时刻 | 研报日期按**目标市场时区**重锚，入场不早于研报日 |

| 前视偏差 | 1,669 条（50.4%）入场早于研报日 | **0** |

根因与修复：`docs/specs/2026-07-27-corpus-wide-entry-lookahead.md`、
`src/finer/extraction/timing_builder.py:resolve_publication_instant`。

## 4. 上一轮国际股结论的复核：全部存活，量级收窄

`2026-07-25-intl-winrate-decomposition.md` 的结论建立在含前视的数据上，逐项复核：

| 结论 | v5 | v6 | 是否存活 |
|---|---|---|---|
| INTL vs 美股缺口 | +14.5pp | **+13.1pp** | ✅ |
| 一半来自 JP/TW/KR | +20.1pp | **+17.7pp** | ✅ |
| 另一半（其余国际） | +8.8pp | **+8.5pp** | ✅ |
| 其余国际均值 ≈ 美股 | +0.22% vs +0.27% | +0.34% vs −0.10% | ⚠️ 见下 |
| 港股悬崖是真的 | 27.0% / −6.64% | **24.5% / −7.21%** | ✅ 更差 |

⚠️ **一处措辞需收紧**：v5 里我说非亚洲国际股与美股均值「完全相同」（+0.22% vs
+0.27%）。v6 下是 +0.34% vs −0.10%，差 0.44pp。两者仍同在零附近、结论
（非亚洲国际股没有实质收益优势，高胜率来自低波动少触止损）不变，
但「完全相同」这个说法应改为「同处零附近，差异远小于 8.5pp 的胜率缺口」。
